# marker

A minimal [Next.js](https://nextjs.org) (App Router) app. The home page renders
"this is marker app".

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Layout

```
src/app/
├── layout.jsx     Root layout
├── page.jsx       Home page — "this is marker app"
└── globals.css    Tailwind entry
```
